# Gram

Gram es un framework puro de Python para construir lenguajes de dominio específico, transpiladores y frontends de compiladores.

Incluye un lexer configurable, combinadores de análisis sintáctico con backtracking, expresiones Pratt, generación de árboles de sintaxis abstracta (AST), diagnósticos detallados y herramientas para VS Code/LSP.

Está diseñado para mantener el núcleo simple y extensible, sin dependencias externas de ejecución. Puedes usarlo para crear parsers, DSLs y herramientas de lenguaje con libertad para distribuir y comercializar el resultado.
