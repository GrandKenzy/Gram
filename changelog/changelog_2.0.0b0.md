# Gram `2.0.0b0`

> **First beta release** · Parser foundations and language tooling

## Highlights

- Pratt expression engine for precedence-aware expression parsing.
- `RayTracing` telemetry for parser execution paths.
- `Hookr` observers for parser lifecycle events.
- Immutable `TokenInfo` snapshots for tooling and diagnostics.
- VNMA compatibility for isolated project installation.
